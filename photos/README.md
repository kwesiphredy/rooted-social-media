# Photos for Rooted posts

Put real photos here (your own, or ones you have the rights to). No AI-generated images.

1. Add the image file to this folder (JPG or PNG, at least 1080 px wide).
2. Add a line for it in `manifest.json`:

```json
{ "file": "sunday-worship-01.jpg", "tags": ["church", "worship"], "people": true, "credit": "Fred Larbi", "used": false }
```

Tags the designs look for: `church`, `worship`, `sermon`, `bible`, `prayer`, `journal`, `phone`, `friends`, `group`, `coffee`, `morning`, `nature`, `christmas`, `easter`, `family`, `mom`.
Only add photos of people who agreed to be in Rooted's posts.
